# 复古手账档案馆网页设计规范

## 1. 风格定位

### 1.1 风格定义
“复古手账档案馆”把情侣网站设计成一本持续增厚的私人手账，也像一个两个人共同维护的记忆档案盒。页面不是单纯展示信息，而是模拟“翻开旧纸页、贴上票根、盖下日期章、整理照片和地图”的过程。

核心关键词：
- 私人档案
- 手账拼贴
- 旧纸张
- 票根邮戳
- 慢节奏记录
- 可持续扩展

### 1.2 适用目标
该风格适合承载纪念日、时光档案、旅行足迹、照片合集等长期积累型内容。它的重点不是强冲击视觉，而是让每个模块都像真实记录物件，有“被保存过”的质感。

### 1.3 设计原则
- 信息像档案一样被收纳：每个模块都有清晰编号、日期和归档感。
- 视觉像手账一样有层次：纸张、贴纸、胶带、票根、照片形成错层。
- 排版避免盒子化：不要把页面切成一个接一个的规则矩形模块，而是用纸页、散落卡片、路线、抽屉和翻页形成自然流动。
- 情绪温暖但不过甜：避免大量粉色和爱心堆叠，用纸张、木色、暖棕表达亲密。
- 组件可持续新增：后续增加旅行、纪念日、照片时，不需要重新设计版式。
- 装饰必须服务信息：邮戳、虚线、纸夹、标签都应对应日期、地点、分类或状态。

## 2. 视觉基调

### 2.1 氛围描述
整体像傍晚灯光下摊开的旧手账。背景是暖米色纸面，局部有浅网格、淡斑点和纸纤维纹理；内容卡片像从不同年份保存下来的纸条、照片、票根和地图页。页面应该有轻微“不完全对齐”的手工感，但不能凌乱。

### 2.2 视觉记忆点
- 首屏像一张打开的手账桌面，纸页、票根、照片和地图碎片不是整齐网格，而是自然压叠在一起。
- 重要日期使用日期章、编号章或票根孔位表达。
- 时光档案以“档案抽屉 / 卡片索引 / 月历贴纸 / 翻页纸条”组织。
- 旅行足迹像贴在纸页上的旧地图，路线可以蜿蜒穿过模块，把多个记忆串起来。
- 相册像拍立得、冲印照片和边角胶带叠放，允许部分照片压住文字边缘但不影响阅读。
- 鼠标经过时纸片轻微错位、贴纸翘起、邮戳落下，让页面有被翻阅和整理的感觉。

## 3. 色彩规范

### 3.1 主色板
| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f7f0e3` | 页面主背景、纸张底色 |
| `--paper-soft` | `#fffdf7` | 卡片、弹层、重点内容纸面 |
| `--ink` | `#24211d` | 主文字、标题、图标深色 |
| `--ink-muted` | `rgba(36, 33, 29, 0.68)` | 正文说明、次级文字 |
| `--stamp` | `#b76e55` | 邮戳、主按钮、重点日期 |
| `--moss` | `#657568` | 地图区域、辅助标签、低饱和装饰 |
| `--gold` | `#c7a356` | 高光、纪念日、年份标识 |
| `--line` | `rgba(80, 52, 36, 0.18)` | 卡片边框、分割线 |
| `--shadow-warm` | `rgba(80, 52, 36, 0.12)` | 纸张投影 |

### 3.2 配色比例
- 背景纸色：约 60%
- 卡片浅纸色：约 20%
- 墨色文字与线条：约 10%
- 赭红邮戳色：约 6%
- 苔绿色与旧金色：约 4%

### 3.3 使用规则
- `#b76e55` 只用于行动按钮、重要日期、印章、选中状态，不大面积铺底。
- `#657568` 适合旅行地图、标签、低优先级装饰，避免和主按钮竞争。
- `#c7a356` 用作小面积高光，例如周年年份、收藏标记、当前月份。
- 大面积背景必须保持低饱和，避免页面变成复古海报而不是手账。

## 4. 字体规范

### 4.1 字体组合
| 层级 | 字体建议 | 用途 |
| --- | --- | --- |
| 标题 | `Georgia`, `"Songti SC"`, serif | 首屏标题、章节标题、纪念日标题 |
| 正文 | `"Avenir Next"`, `"PingFang SC"`, `"Hiragino Sans GB"`, sans-serif | 段落、说明、按钮 |
| 档案编号 | `"SFMono-Regular"`, `"Menlo"`, monospace | 日期、编号、坐标、归档 ID |

### 4.2 字号层级
| Token | 桌面端 | 移动端 | 用途 |
| --- | --- | --- | --- |
| `display` | `72-96px` | `42-56px` | 首页大标题 |
| `section-title` | `48-64px` | `34-42px` | 模块标题 |
| `card-title` | `22-30px` | `20-24px` | 卡片标题 |
| `body` | `16-18px` | `15-16px` | 正文说明 |
| `caption` | `12-13px` | `11-12px` | 编号、标签、日期 |

### 4.3 排版规则
- 标题允许紧凑，建议 `line-height: 0.92-1.08`，营造手账封面感。
- 正文必须宽松，建议 `line-height: 1.75-1.9`，保持阅读舒适。
- 日期、坐标、编号使用等宽字体，增强档案感。
- 中文标题不要全字距拉开，编号和英文标签可使用 `letter-spacing: 0.12em`。

## 5. 页面结构

### 5.1 整体布局
页面以“档案册”作为主隐喻，但版式不按传统卡片网格切块。建议使用“主叙事路径 + 自由拼贴区 + 局部抽屉”的结构：

1. 打开的手账封面：展示站点名称、关系主题、档案编号、主行动按钮。
2. 漂浮索引贴纸：近期纪念日、旅行更新、相册新增以贴纸散落在首屏周围。
3. 纪念日时间绳：用一条手绘线串起重要日期，而不是普通卡片列表。
4. 时光档案抽屉：年月筛选像抽屉标签，事件像抽出的索引纸条。
5. 旅行足迹纸地图：地图、票根、城市标签互相压叠，路线穿插其间。
6. 相册拼贴墙：拍立得和文字便签自由排布，重点照片可以突破规整容器。
7. 档案袋封底：放维护说明、最后更新时间和下一次记录入口。

### 5.2 桌面端网格
- 页面容器：`max-width: 1180-1280px`
- 外边距：`32-48px`
- 主栅格：12 列只作为隐形对齐基准，不直接暴露成规则卡片矩阵
- 模块间距：`88-128px`
- 卡片间距：`18-28px`

推荐首屏布局：
- 左侧 6-7 列：标题、描述、按钮、当前档案编号
- 右侧和标题周围：错层纸页、票根、日期章、地图碎片、照片贴纸自由压叠
- 允许 1-2 个元素跨越常规列边界，制造“桌面摊开”的感觉

### 5.3 非盒子化排版规则
- 避免连续出现同尺寸、同圆角、同边框的卡片。
- 重要模块可以使用“纸片群”替代单一容器，例如一张主纸页叠两张便签和一张票根。
- 容器边界可以被胶带、照片、邮戳、路线穿出，但文字阅读区域必须清晰。
- 列表类信息不要全部装进卡片，可改为时间绳、索引条、票根串、抽屉标签。
- 每屏至少有一个元素表现出自然叠放：压住、露出、夹住、翻起或半展开。
- 留白要像纸面空隙，不要像后台管理系统的栅格间距。

### 5.4 移动端布局
- 改为单列流式堆叠。
- 装饰减少 40%-60%，保留邮戳、胶带、纸张边缘。
- 卡片旋转角度减小或取消，避免窄屏拥挤。
- 粘性导航如果保留，应改为横向滚动标签。

## 6. 核心组件规范

### 6.1 纸张卡片
用途：纪念日、档案事件、旅行城市、相册条目。

视觉规则：
- 背景：`rgba(255, 253, 247, 0.86)`
- 边框：`1px solid var(--line)`
- 圆角：`4px 22px 22px 22px`
- 投影：`10px 16px 0 rgba(183, 110, 85, 0.08), 0 20px 50px var(--shadow-warm)`
- 内边距：`24-34px`
- 可轻微旋转：`-1.5deg` 到 `1.5deg`

状态规则：
- Hover：上移 `-4px`，阴影加深，贴纸/胶带微动。
- Active：边框变为 `rgba(183, 110, 85, 0.44)`。
- Disabled：降低透明度，不使用灰色大面积覆盖。

### 6.2 邮戳标签
用途：档案编号、年份、重要状态。

视觉规则：
- 边框：`2px solid var(--stamp)`
- 文字：`var(--stamp)`
- 字体：等宽或粗体无衬线
- 字号：`11-13px`
- 字距：`0.12em`
- 角度：`rotate(-6deg)`，不同场景可在 `-8deg` 到 `5deg` 内变化。

推荐文案：
- `ARCHIVE 001`
- `SINCE 2019`
- `TRAVEL LOG`
- `ANNIVERSARY`
- `MEMORY SAVED`

### 6.3 主按钮
用途：首屏行动、查看纪念册、进入地图、查看档案。

视觉规则：
- 背景：`var(--stamp)`
- 文字：`#fffdf7`
- 圆角：`999px`
- 高度：`44-52px`
- 横向内边距：`18-26px`
- 投影：`0 10px 0 rgba(183, 110, 85, 0.18)`

交互：
- Hover：`transform: translateY(-2px)`，投影略加深。
- Pressed：`transform: translateY(2px)`，投影缩短。

### 6.4 次级按钮 / 筛选标签
用途：年份、月份、国家/城市筛选。

视觉规则：
- 背景：透明或 `rgba(255,253,247,0.55)`
- 边框：`1px dashed rgba(80, 52, 36, 0.28)`
- 文字：`var(--ink)`
- 选中：背景 `rgba(183, 110, 85, 0.12)`，边框改实线，文字为 `var(--stamp)`。

### 6.5 日期章
用途：纪念日、周年提示、档案事件日期。

结构：
- 月日大字：`02.02`
- 年份小字：`SINCE 2019`
- 事件类型：`恋爱日 / 旅行 / 相册`

视觉规则：
- 可做成圆章或矩形章。
- 章体颜色用 `--stamp` 或 `--gold`。
- 避免每个卡片都盖大章，重要事件才使用完整日期章。

### 6.6 胶带与贴纸
用途：增强手工拼贴感。

视觉规则：
- 胶带背景：`rgba(199, 163, 86, 0.22)` 或 `rgba(255, 253, 247, 0.62)`
- 胶带位置：卡片左上、右上或照片边角。
- 旋转角度：`-4deg` 到 `4deg`
- 不应遮挡关键信息。

### 6.7 拍立得照片卡
用途：相册、精选照片、旅行图片。

视觉规则：
- 白色厚边框，底部边框更厚。
- 图片比例：`4:3` 或 `1:1`
- 底部可写日期、地点、短句。
- 多张照片错层排列，但同屏最多 3-5 张，避免杂乱。

## 7. 业务模块设计

### 7.1 首页 Hero
目标：第一眼建立“私人档案册”的记忆点。

推荐内容：
- 邮戳：`ARCHIVE 001`
- 主标题：`把日子装进一本慢慢变厚的手账`
- 副文案：说明纪念日、旅行、档案都被收纳在这里。
- 主按钮：`查看纪念册`
- 次按钮：`打开旅行地图`

视觉结构：
- 左侧为大标题和按钮。
- 右侧为 3-4 张错层纸卡：最近纪念日、旅行票根、地图贴纸、相册预览。
- 背景使用浅网格纸纹和局部暖色光斑。

### 7.2 纪念时刻
目标：让日期具有“盖章保存”的仪式感。

布局：
- 顶部为模块标题和说明。
- 下方使用横向索引卡或 2-3 列卡片。
- 每张卡包含：日期、标题、已过去/第几年、说明、来源。

组件建议：
- 重要纪念日使用大日期章。
- 普通纪念日使用小标签。
- 当前月份的纪念日可贴一个 `THIS MONTH` 标签。

### 7.3 时光档案
目标：记录每个重要日子，同时避免信息密度失控。

布局：
- 左侧或顶部：年月筛选器，像档案柜抽屉标签。
- 主体：档案卡片列表。
- 辅助：小月历贴纸显示有事件的日期。

卡片字段：
- 日期
- 类型：纪念日 / 旅行 / 独立档案 / 相册
- 标题
- 简短描述
- 来源标记：`ANNIVERSARY`、`TRAVEL`、`NOTE`

视觉规则：
- 同一天多条事件时，合并在同一张“日期档案卡”内。
- 每条来源用不同小色条区分，避免全靠文字识别。

### 7.4 旅行足迹
目标：让地图像一张被反复标注的纸质旅行图。

布局：
- 地图区域像旧地图纸，底色偏米黄。
- 已访问区域使用苔绿色或赭红浅填充。
- 右侧或下方使用旅行票根列表。

视觉规则：
- 中国城市和世界国家填色保持温和，不用高饱和地图色。
- 地名标签可像地图铅字，颜色用 `rgba(36,33,29,0.64)`。
- 已访问点可以用印章点或小贴纸，但中国地图当前正式需求是不显示图钉时，应只用填色和列表说明。

### 7.5 相册
目标：照片像从手账里翻出来，而不是普通图片网格。

布局：
- 重点照片使用大拍立得。
- 辅助照片用 2-4 张错层小卡。
- 每组照片可配一个票根式标题，标明地点和日期。

交互：
- Hover 时照片轻微抬起。
- 点击打开详情时，弹层像展开一页相册纸。

## 8. 装饰系统

### 8.1 背景纹理
允许使用：
- 浅网格线
- 纸张噪点
- 轻微水渍
- 边缘暗角
- 局部暖色光晕

禁止使用：
- 高对比复古花纹大面积铺底
- 过重噪点影响阅读
- 拟真到压过内容的纸张纹理

### 8.2 分隔方式
优先使用：
- 虚线裁切
- 档案标签页
- 票根齿孔
- 纸张错层

避免使用：
- 纯现代直线分割
- 大面积玻璃拟态
- 霓虹发光线

### 8.3 图标风格
图标应像手账小印章或铅笔线稿：
- 线宽：`1.5-2px`
- 圆角端点
- 低饱和颜色
- 不使用过于科技感的锐角图标

## 9. 动效规范

### 9.1 动效原则
动效要像纸张、贴纸和档案被轻轻移动，不应像科技产品一样快速弹跳。

交互目标不是“按钮可点”这么简单，而是让用户感觉自己正在翻阅、整理、抽取和标记记忆。每个主要模块都应至少有一种轻量交互。

### 9.2 推荐动效
| 场景 | 动效 |
| --- | --- |
| 页面进入 | 纸卡从下方轻微浮现，透明度从 0 到 1 |
| 卡片 Hover | 上移 4px，旋转角度回正 0.5deg |
| 邮戳出现 | 轻微缩放和旋转，像盖章落下 |
| 相册打开 | 纸页展开或卡片滑出 |
| 时间轴切换 | 档案卡按日期顺序错峰出现 |
| 地图切换 | 旧地图淡入，访问区域像墨迹逐渐显现 |
| 纪念日浏览 | 日期沿手绘线逐个点亮，当前日期章轻轻压下 |
| 时光档案筛选 | 年份标签像抽屉拉出，事件纸条从下方滑出 |
| 旅行城市 Hover | 地图上路线轻微发亮，旁边票根抬起 |
| 照片查看 | 拍立得从拼贴墙中被抽出，背景纸片轻微散开 |

### 9.3 交互方式建议
- **翻页**：用于时光档案按月份/年份切换，适合桌面端和移动端。
- **抽屉**：用于筛选年份、事件类型、城市国家，点击后像档案柜标签被拉开。
- **手绘路线游走**：用于旅行足迹或时间线，滚动时路线逐段显现。
- **纸片展开**：用于查看详情，默认只露出标题和日期，点击后展开描述。
- **贴纸标记**：用户 hover 或选中某个事件时，贴纸浮起并露出来源标签。
- **轻量拖拽感**：桌面端可让精选照片或便签有拖拽提示，但不要求真正改变数据顺序。

### 9.4 参数建议
- 时长：`180-420ms`
- 缓动：`cubic-bezier(0.2, 0.8, 0.2, 1)`
- 进入错峰：`40-80ms`
- 旋转角度：不超过 `2deg`
- 位移：不超过 `16px`

## 10. 图片与插画规范

### 10.1 图片风格
照片应保持真实生活感，可加轻微暖色滤镜：
- 亮度略提升
- 对比略降低
- 色温偏暖
- 暗角轻微
- 不使用过强胶片颗粒

### 10.2 插画元素
可使用：
- 票根
- 纸夹
- 邮票
- 城市坐标贴纸
- 手绘路线
- 档案编号条

插画应作为辅助层，不应替代真实内容。

## 11. 响应式规范

### 11.1 断点建议
| 断点 | 布局 |
| --- | --- |
| `>= 1200px` | 12 列完整档案册布局 |
| `768px - 1199px` | 8 列或两列布局，减少装饰 |
| `< 768px` | 单列，卡片堆叠，导航横滑 |

### 11.2 移动端取舍
- 保留纸张、邮戳、日期章三个核心记忆点。
- 弱化复杂错层和旋转。
- 地图模块优先保证可读性，装饰放到外围。
- 卡片间距不小于 `14px`，正文不小于 `15px`。

## 12. 可访问性与可维护性

### 12.1 可访问性
- 正文对比度需满足基本阅读，避免浅棕文字叠在深纹理上。
- 关键信息不能只靠颜色区分，需同时有文字标签。
- Hover 效果必须有非 hover 的可见状态。
- 动效应尊重 `prefers-reduced-motion`。
- 邮戳类文字不可过度倾斜，避免难读。

### 12.2 可维护性
- 所有颜色应抽成 CSS 变量。
- 装饰元素尽量用伪元素和可复用类，不为每张卡写独立样式。
- 数据仍来自现有独立数据文件，不把文案重新写死到组件里。
- 业务模块结构不应为了装饰改变数据模型。

## 17. 验收标准

该风格落地后应满足：
- 用户第一眼能识别出“手账 / 档案 / 旧纸张”的视觉主题。
- 页面仍能清晰阅读，不因装饰降低信息效率。
- 纪念日、时光档案、旅行足迹、相册四类内容看起来属于同一套系统。
- 新增一条纪念日或旅行记录后，视觉结构不需要额外手工调整。
- 移动端保留核心风格记忆点，不出现拥挤和错位。
